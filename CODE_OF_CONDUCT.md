# Code of Conduct

RPGCreatorAI aims to be a practical, respectful open source project.

## Expected Behavior

- Be direct, constructive, and specific.
- Assume contributors are here to improve the project.
- Critique code, design, and tradeoffs without attacking people.
- Keep issues and pull requests focused on the project.

## Unacceptable Behavior

- Harassment, insults, threats, or discrimination.
- Publishing private information without permission.
- Repeated off-topic arguments after maintainers ask to stop.
- Spam or low-effort promotional content.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; block users; or restrict participation when behavior harms the project.

If you need to report conduct concerns, contact the maintainer through GitHub profile contact methods.
