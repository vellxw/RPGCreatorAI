This folder is an RPGCreatorAI project. The executable game data lives under
`data/`; source and imported media live under `assets/`. The files below are
the human-readable project contract:

- `GAME_DESIGN.md` — what the player does, why it is compelling, and what is
  in scope.
- `GAME_STYLE.md` — the binding visual and sensory direction for this game.
- `TECHNICAL.md` — supported runtime targets, data constraints, budgets, and
  validation/release expectations.
- `ASSETS.md` — asset ownership, licensing, attribution, provenance, and
  readiness.
- `foundation-manifest.json` — optional machine-readable index of these
  documents; it is not runtime data.
