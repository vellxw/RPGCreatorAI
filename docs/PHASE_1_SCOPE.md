# Phase 1 Scope

## Goal
A minimal, data-driven C++ RPG engine capable of executing a playable scene defined entirely in JSON.

## Included
- Window creation (SDL2)
- JSON parsing (nlohmann/json)
- Basic 2D tile-based rendering
- Grid movement & collision
- Event system (text, flags, items, transfers)
- Save/Load functionality (JSON)
- Clean, modular architecture

## Excluded
- Visual Editor
- Combat
- complex UI
- Audio (stubbed)
- Complex graphics (using colored rects as placeholders)
- Advanced scripting
